# Doom-ish (1993-style) Raycaster — HTML

Single-file, dependency-free Doom/Wolf3D-era raycaster demo.

## Run locally
Open `index.html` in a browser.

Controls:
- W/A/S/D: move + strafe
- Arrow keys: turn
- Shift: run
- Space: shoot
- P: pause

Tip: click the canvas for pointer lock (mouse look).

## GitHub Pages
Enable Pages (Settings → Pages) and it serves `/index.html`.
