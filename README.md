# Doom-ish (1993-style) Raycaster

A single-file, Doom/Wolfenstein-era style **2.5D raycaster** built in plain HTML + JS.

Play it here:
https://timclawdbot-rgb.github.io/doom/

## Controls

### Desktop (keyboard + mouse)

- **W/A/S/D**: move + strafe
- **← / →**: turn
- **Shift**: run
- **Space**: shoot
- **P**: pause
- **Mouse look**: click the canvas to request pointer lock (if supported)

### Mobile (touch)

- **Left analog stick (bottom-left)**: move + strafe
- **Right analog stick (right side)**: aim/turn
- **SHOOT button (bottom-right)**: shoot

Tip: If controls don’t update immediately on mobile, do a hard refresh (GitHub Pages caching).
